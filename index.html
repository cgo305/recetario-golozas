Cómo obtener el token

1. Entra a github.com/settings/tokens y elige «Generate new token (classic)».

2. Marca únicamente el permiso gist. No marques repo: con solo «gist» este token no puede tocar tus repositorios.

3. Cópialo y pégalo aquí abajo. Repite lo mismo en tu otro dispositivo con el mismo token.

Se guarda solo en este navegador. Quien pueda usar este dispositivo podrá verlo.

Déjalo vacío en el primer dispositivo: se crea automáticamente. Después copia aquí ese mismo identificador en los demás.

Qué significa para tu privacidad

El gist es privado, es decir, no aparece en búsquedas. Pero no está cifrado: quien tenga su dirección puede leerlo, y GitHub también. Si prefieres que nadie más pueda leerlas, pídeme la versión cifrada.
